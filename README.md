# 🧭 Smart Mobile Travel Guide App – Concord Travels

**A Flutter-based intelligent travel guide app** tailored for modern tourists, enhancing the travel experience through tour planning, real-time chat, and personalized recommendations.

---

## 📱 Project Overview

This application is a **smart mobile travel guide** built to help travelers plan, book, and manage their trips with ease. It integrates advanced features such as real-time chatbot-based recommendations, personalized tour selection, booking management, and admin control.

The project addresses existing gaps in travel apps by offering:

- ✅ Efficient tour package management  
- ✅ Centralized booking oversight  
- ✅ Interactive user-admin communication  
- ✅ Real-time AI-assisted chatbot  
- ✅ Custom recommendations based on preferences  

---

## 🔧 Technologies Used

- **Frontend:** Flutter (Dart)  
- **Backend:** Firebase (Cloud Firestore, Firebase Auth, Firebase Storage)  
- **State Management:** Provider  
- **Other Tools:** Trello (Kanban Board), Image Picker, Path Provider  

---

## 🚀 Features

### 👤 Tourist/User Side

- Browse & search tour packages  
- View detailed tour info (name, city, duration, cost, etc.)  
- Book and pay for tours  
- Receive recommendations from chatbot  
- View booking & payment history  
- Save favorites  
- Profile management (edit/delete)  
- Feedback/enquiry system  
- Notifications  

### 🛠️ Admin Side

- Add/update/delete tour packages  
- View all bookings (upcoming/cancelled)  
- Manage user enquiries and provide responses  
- View and resolve feedback  
- Monitor system and user interactions  

---
